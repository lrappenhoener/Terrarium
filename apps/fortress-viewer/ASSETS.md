# Assets

The viewer ships no image, font or sound files. All graphics are shapes drawn in
code in `src/render.rs` (rectangles, triangles, circles and lines in self-chosen
colors) and are part of this repository's own work.

| Asset | Source | License |
| --- | --- | --- |
| Tile, item, resident and overlay shapes | own work, `src/render.rs` | same as the repository |
| Screenshots in `docs/` | rendered by this viewer | same as the repository |
| Text font | built into the `macroquad` library (default UI font), not a file of this repository | MIT OR Apache-2.0, see the `macroquad` crate |
